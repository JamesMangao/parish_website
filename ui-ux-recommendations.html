This document provides a comprehensive UI/UX audit of the Sto. Rosario Parish website, covering all public-facing pages. Each section identifies what's working well, specific issues to fix, and new features to consider. Recommendations are ordered by page, then by impact.

Overall Assessment

The site has a strong visual identity — the maroon/gold/cream palette, Canterbury and Cormorant Garamond fonts, and consistent card-based layouts create a premium, reverent feel. The main areas for improvement are consistency, accessibility, and dynamic content management.

1 Home Page

Strengths What's Working Well

  • Hero section is visually stunning — Canterbury font, gold accents, radial gradients create a premium feel
  • Quick Access cards are clean and well-organized
  • Events section with featured next Mass is smart and functional
  • Announcement carousel with featured card is well thought out
  • Sacramental Services grid is scannable and well-designed

Fix Inconsistent Mass Count

Critical — Trust Issue

The hero stats strip says "7 Weekly Masses" but the About page stats bar says "13 Weekly Masses." This inconsistency undermines credibility. Both should pull from a single dynamic source in settings.

Fix Excessive Card Padding

The "How Can We Serve You?" cards contain <br><br> tags that create unnecessary whitespace inside each card link. Remove them for tighter, more clickable card targets.

New Mobile Navigation Drawer

The mobile hamburger menu transitions from hamburger → X, but the drawer itself uses a simple fade. A slide-in-from-right pattern would be more intuitive and match common mobile navigation patterns.

New Breadcrumb Trail

On sub-pages (Mass Schedule, Events, Gallery), there is no breadcrumb or "You are here" indicator. Adding a simple breadcrumb trail (e.g., Home › Mass Schedule) improves wayfinding and reduces back-button reliance.

Fix Hardcoded Footer Mass Times

The footer displays "Sunday Mass: 6:30 AM, 8:30 AM, 10:00 AM, 3:00 PM, 4:30 PM, 6:00 PM" as hardcoded text. If schedule changes, the footer becomes stale. Either pull from settings or replace with a link to the Mass Schedule page.

New Favicon & PWA Manifest

Verify that a favicon and manifest.json are configured for mobile bookmarking and home screen support. This is a quick win for professional appearance on mobile devices.

2 Mass Schedule Page

Strengths What's Working Well

  • Card layout with sidebar + content is elegant and scannable
  • Time chips are visually clear with good hover states
  • Google Calendar and iCal export buttons are an excellent UX touch
  • Special Masses note with Facebook link is helpful

Fix Calendar Buttons Need Labels

The "Add to Google Calendar" and "Download .ics" buttons show only small icons with no visible text. Add tooltips or visible labels like "Add to Google Calendar" / "Download .ics" for clarity, especially for less tech-savvy visitors.

New "Today" Indicator

When viewing the schedule, there's no visual highlight showing which schedule applies today. A subtle "Today" badge on the current day's card, or a highlighted time chip, would help visitors find relevant times immediately.

New Weekly Grid View Option

Some visitors prefer seeing the entire week at a glance. A toggle between "List View" (current) and "Weekly Grid" (Mon–Sun columns) would serve different user preferences and reduce scrolling.

Fix Empty State Could Be More Helpful

The "No Schedules Available" empty state is clean but could link to the inquiry form or display the parish office contact info for manual scheduling assistance.

3 About Page

Strengths What's Working Well

  • Excellent visual hierarchy and section flow
  • Horizontal timeline with drag-to-scroll is engaging
  • Patron Saints section with large images is beautiful
  • Leadership cards with priest contributions are well-designed
  • Leaflet map with custom styled marker is a nice touch

Fix Stats Bar Inconsistency

"43+ Years of Service" and "13 Weekly Masses" are good. However, verify that the "43+" calculation is accurate (founded 1983, current year 2026 = 43 years). Consider adding "Active Ministries" or "Registered Families" for more community feel.

New Sub-Headings in "Our Calling"

The three paragraphs about the patroness, cultural property designation, and welcome message are one continuous flow. Breaking them into 2–3 distinct sub-sections with mini headings (e.g., "Our Patroness," "Cultural Heritage," "Welcome") would improve scanability.

Fix Timeline Arrow Overlap on Mobile

The left/right arrow buttons for the horizontal timeline may overlap with content on smaller screens. Add responsive positioning or hide them on mobile in favor of swipe gestures only.

Fix Timeline "Read More" Accessibility

The timeline expand/collapse uses a plain <span> with onclick. Convert it to a <button> with aria-expanded and aria-controls for screen reader support. This is an accessibility violation (WCAG 2.1).

Fix Map Popup Hardcoded Text

The Leaflet map popup displays "Sto. Rosario Parish" and the address in hardcoded JavaScript. Pull these values from $global_settings for consistency with the rest of the site.

4 Donate Page

Strengths What's Working Well

  • Three-tab payment system (Online, QR, Bank) is well-organized
  • QR code copy-to-clipboard functionality is excellent
  • "Where your donation goes" sidebar builds trust and transparency
  • Scripture quote adds a meaningful spiritual touch
  • Amount preset buttons with custom option are user-friendly

Fix "Coming Soon" State Needs Redirect

Instead of just saying "Coming Soon" for online payments, add a "Notify Me" email capture or a prominent "In the meantime, try QR →" CTA to redirect users to an available payment method.

Fix Amount Resets When Switching Tabs

When switching between tabs (Online → QR → Bank), the selected donation amount resets to 0. Keep the amount state persistent across all tabs.

New Donation Confirmation Summary

After submitting, there's no visual summary of what was donated. A confirmation card showing amount, method, and a personalized thank-you message would improve trust and reduce post-donation anxiety.

New Impact Counter / Social Proof

A subtle "₱X,XXX donated this month" or "142 families supported this quarter" counter builds social proof and encourages giving. Even a static number updated monthly would help.

5 Events Page

New Monthly Calendar View

A traditional calendar grid view (monthly) would complement the list view and help visitors see the full month at a glance. Consider a toggle between "List" and "Calendar" views.

New RSVP / Interest Button

For events, adding a simple RSVP button (even if it just sends an email notification to the office) would increase engagement and help the parish plan for attendance.

New Event Images / Thumbnails

Most event cards show only text and icons. Encouraging event images or thumbnails would make the page more visually engaging and help visitors quickly identify events they recognize.

6 Gallery Page

Fix Lazy Loading for Images

Gallery images should use loading="lazy" and consider an Intersection Observer for progressive loading. This improves initial page load performance significantly.

New Download Option for Photos

Visiting parishioners may want to download event photos. Add a subtle download button that appears on hover for individual photos.

New Search & Filter

As the gallery grows, finding specific events becomes harder. Add a date range filter, event-type filter, or keyword search to help visitors find photos quickly.

7 Inquiry / Submit Intention

New Progress Indicator

If these are multi-step forms, show a progress bar (e.g., "Step 1 of 3") so users know how much is left and feel a sense of completion.

New Auto-Save / Draft

Long forms should auto-save progress to prevent data loss on accidental navigation or browser close. This is especially important for detailed sacramental inquiries.

New Submission Summary Card

After submission, show a summary card with all entered details for the user to review. Include a reference/tracking number and expected response time.

8 Global / Cross-Cutting

New Page Transition Animations

Different pages load abruptly. A subtle fade-in or slide-up transition when navigating between pages would feel more polished and professional.

New Global "Back to Top" Button

Currently present on some pages but not all. Make it global, consistent, and ensure it doesn't conflict with the map z-index (already fixed in navbar).

New Unique Open Graph Images

Most pages share the same OG image for social media. Create unique OG images for key pages (About, Mass Schedule, Donate) for better social media previews and click-through rates.

New Site-Wide Search

As content grows (announcements, events, gallery albums), a search function in the navbar would help users find what they need without navigating through menus.

New "Last Updated" Timestamps

Show "Last updated: Aug 18, 2026" on Mass Schedule and About pages to build trust that the information is current and actively maintained.

Fix Inconsistent Loading States

Some pages show skeleton loaders (good!), but not all data-driven pages do. Standardize skeleton loading across all pages that fetch data for a consistent experience.

New Page Feedback Widget

A small "Was this page helpful?" widget at the bottom of key pages would gather user feedback and help prioritize future content and design improvements.

New Newsletter Signup in Footer

The footer is functional but static. Adding an email newsletter signup would build a direct communication channel with parishioners for announcements and events.
